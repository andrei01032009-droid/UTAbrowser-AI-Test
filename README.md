# 🦊 UTA Browser

**UTA** — простой браузер, написанный с помощью AI (Wibecode). Это основа: строка поиска, заход на сайты и вход в аккаунт через Google.

## Что уже умеет (основа)

- 🔍 **Поиск и адресная строка** — вводишь адрес сайта (`wikipedia.org`) или запрос, UTA сам понимает, что ты хочешь. Поисковик можно выбрать: DuckDuckGo, Google, Яндекс, Bing.
- 🌐 **Заход на сайты** — результат (сайт или страница поиска) открывается напрямую в новой вкладке. Без прокси — просто и надёжно.
- 🕘 **История** — недавние сайты и запросы сохраняются на главной странице.
- 🔐 **Регистрация и вход через Google** — OAuth 2.0. Аккаунт создаётся автоматически при первом входе. Пока ключи Google не настроены — работает демо-вход.

## Как открыть UTA

### Вариант 1. Через Arena (ничего устанавливать не нужно)
Открой в Arena панель **LIVE PREVIEW** — там уже запущен UTA.

### Вариант 2. На своём компьютере (Windows)
1. Установи **Node.js LTS** с https://nodejs.org (проверить: `node --version` в командной строке)
2. Скачай код: зелёная кнопка **Code → Download ZIP** на GitHub и распакуй
   *(или: `git clone https://github.com/andrei01032009-droid/UTAbrowser-AI-Test.git`)*
3. Дважды кликни **`start.bat`** — он сам всё установит и запустит
4. Открой http://localhost:3000

### Вариант 3. На своём компьютере (macOS / Linux)
```bash
npm install
npm start
```
Открой http://localhost:3000. Для разработки: `npm run dev`.

> ⚠️ Если видишь **«Не удается получить доступ к сайту. Сайт localhost не позволяет установить соединение»** — это значит, что сервер UTA не запущен на твоём компьютере. Запусти `start.bat` (или `npm start`) и не закрывай окно, пока пользуешься UTA.

## Вход через Google (OAuth 2.0)

Без настроек вход работает в **демо-режиме** (тестовый аккаунт). Чтобы включить настоящий вход через Google:

1. Зайди в [Google Cloud Console](https://console.cloud.google.com).
2. Создай проект → **APIs & Services** → **OAuth consent screen** → тип *External* → заполни название (например, UTA) и добавь себя в *Test users*.
3. **Credentials** → **Create credentials** → **OAuth client ID** → тип **Web application**.
4. В поле *Authorized redirect URIs* укажи: `http://localhost:3000/auth/google/callback`
5. Скопируй `.env.example` в `.env` и вставь `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`.
6. Перезапусти UTA — кнопка «Войти через Google» начнёт настоящий вход.

## Как это работает

```
public/          — интерфейс (главная, вход, стили, скрипты)
server.js        — Express-сервер: страницы и аккаунты
lib/store.js     — простое JSON-хранилище (пользователи и сессии)
data/            — создаётся автоматически, в git не попадает
start.bat        — запуск в один клик на Windows
```

UTA — это стартовая страница: она принимает запрос, определяет, адрес это или поиск, и открывает результат в новой вкладке твоего браузера. Раньше была попытка показывать сайты внутри UTA через прокси, но мы её убрали — она давала белые экраны в песочнице.
