# 🦊 UTA Browser

**UTA** — простой браузер, написанный с помощью AI (Wibecode). Это основа: пока что в нём есть самое главное — строка поиска, просмотр сайтов и вход в аккаунт через Google.

## Что уже умеет (основа)

- 🔍 **Поиск и адресная строка** — вводишь адрес сайта (`wikipedia.org`) или запрос, UTA сам понимает, что ты хочешь. Поисковик можно выбрать: DuckDuckGo, Google, Яндекс, Bing.
- 🌐 **Открытие сайтов** — сайты загружаются прямо внутри UTA через встроенный прокси: ссылки и формы работают, как в настоящем браузере.
- ◀️ ▶️ **Навигация** — кнопки «Назад», «Вперёд», «Обновить», адресная строка, история посещений.
- 🔐 **Регистрация и вход через Google** — OAuth 2.0. Аккаунт создаётся автоматически при первом входе. Если ключи Google не настроены — работает демо-вход.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Открой http://localhost:3000

Для разработки (автоперезапуск при изменении файлов): `npm run dev`.

## Вход через Google (OAuth 2.0)

Без настроек вход работает в **демо-режиме**. Чтобы включить настоящий вход через Google:

1. Зайди в [Google Cloud Console](https://console.cloud.google.com).
2. Создай проект → **APIs & Services** → **OAuth consent screen** → тип *External* → заполни название (например, UTA) и добавь себя в *Test users*.
3. **Credentials** → **Create credentials** → **OAuth client ID** → тип **Web application**.
4. В поле *Authorized redirect URIs* укажи: `http://localhost:3000/auth/google/callback`
5. Скопируй `.env.example` в `.env` и вставь `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`.

## Как это работает

```
public/          — интерфейс (главная, вход, окно браузера, стили, скрипты)
server.js        — Express-сервер: страницы, аккаунты, прокси
lib/proxy.js     — ядро браузера: загрузка сайтов и переписывание страниц
lib/store.js     — простое JSON-хранилище (пользователи и сессии)
data/            — создаётся автоматически, в git не попадает
```

Сайты загружаются на сервере и показываются во вкладке. В каждую страницу встраивается небольшой скрипт, который направляет клики и формы через прокси, а страница выполняется в песочнице (CSP `sandbox`), поэтому код сайтов не имеет доступа к данным UTA.

**Запасной режим.** Если сервер UTA не смог загрузить сайт (нет доступа в интернет или сайт блокирует сервер), браузер автоматически пробует загрузить страницу через публичные CORS-прокси прямо из браузера пользователя. Если не помогло и это — внизу есть кнопка «Открыть напрямую в новой вкладке», она работает всегда.

## Ограничения прототипа

Это основа, а не полноценный браузер: некоторые сайты могут частично не работать (сложные SPA, сайты с защитой от ботов, вход на сайтах со сторонними куками, сайты с запретом встраивания во фрейм). Лучше всего работают обычные сайты и DuckDuckGo (легковесная версия поиска).
